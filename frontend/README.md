tag# Cold Email Admin (Next.js)
Deployment: Vercel.

## Setup
```bash
npm install
cp .env.example .env.local
npm run dev
```

## Pages
- `/login` - admin login
- `/` - dashboard
- `/mailboxes` - add/manage SMTP mailboxes
- `/leads` - leads list + CSV upload
- `/campaigns` - create campaigns + run/populate
- `/settings` - setup admin
